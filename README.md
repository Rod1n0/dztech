## 2. Application / Store Name
**DzTech Store** — Online Computer Hardware & Peripherals Store.

## 3. Application Description
DzTech Store is a component-based e-commerce web application built with React.js and Redux. It allows users to browse a curated catalog of laptops, monitors, audio gear, peripherals, and PC components, search and filter items in real time, inspect hardware specifications, toggle between dark and light themes, and manage a persistent shopping cart through global state management.

## 4. Technologies Used
- **React.js (Vite):** Component-based UI architecture, JSX templating, props, and local state hooks (`useState`, `useEffect`, `useMemo`).
- **Redux:** Centralized global state store (`createStore`), explicit action creators, and pure reducer functions.
- **React-Redux:** Connecting React components to the Redux store via `<Provider>`, `useSelector`, and `useDispatch`.
- **JavaScript (ES6+):** Modular application logic, array filtering/sorting, and browser `localStorage` synchronization.
- **CSS3:** Custom minimal dark/light design system built with CSS custom properties
